# ME-Learning Frontend Routes

> ระบบ e-Learning หลักสูตรพัฒนาศักยภาพนักติดตาม ประเมินผลการบริหารและการจัดการศึกษาขั้นพื้นฐาน  
> **4 กลุ่มผู้ใช้: Guest / Learner / Expert / Admin**

---

## สรุปภาพรวม

| กลุ่ม | จำนวน Route | คำอธิบาย |
|-------|-------------|----------|
| Public (Guest) | 7 | หน้าที่ไม่ต้อง login |
| Learner | 10 | ผู้เรียนทั่วไป + ผู้เรียน สตผ. |
| Expert | 6 | ผู้เชี่ยวชาญ (ตรวจใบงาน) |
| Admin | 12 | Admin สตผ. (จัดการระบบ) |
| **รวม** | **35 Routes** | |

## 1. Public Routes (ไม่ต้อง Login)

| # | Route | Page | คำอธิบาย |
|---|-------|------|----------|
| 1 | `/` | หน้าแรก (Landing) | แสดงรายละเอียดหลักสูตร, คำอธิบาย, ระยะเวลา, วิทยากร, เนื้อหา Module, จำนวนผู้เรียน, จำนวนผู้ผ่าน, คะแนนรีวิวเฉลี่ย, ความคิดเห็นจากผู้เรียน, ปุ่ม "เข้าสู่ระบบ" / "ลงทะเบียน" |
| 2 | `/courses` | รายการหลักสูตร | แสดงหลักสูตรทั้งหมดที่เผยแพร่ (กรณีมีหลายหลักสูตร) พร้อมข้อมูลสรุป rating, จำนวนผู้เรียน |
| 3 | `/courses/:courseId` | รายละเอียดหลักสูตร | Tab: รายละเอียด / วิทยากร / เนื้อหาหลักสูตร (ชื่อ Module + หัวข้อย่อย), รีวิวจากผู้เรียน, ปุ่ม "เข้าสู่บทเรียน" |
| 4 | `/register` | ลงทะเบียน | ฟอร์ม: คำนำหน้า, ชื่อ, นามสกุล, อีเมล, รหัสผ่าน, ยืนยันรหัสผ่าน, ตำแหน่ง (dropdown), ตำแหน่งอื่น ๆ, ประสบการณ์, สังกัด (dropdown 245 เขต), สถานศึกษา, เบอร์ติดต่อ |
| 5 | `/login` | เข้าสู่ระบบ | ฟอร์ม: อีเมล + รหัสผ่าน, ลิงก์ "ลืมรหัสผ่าน", ลิงก์ "ยังไม่ได้ลงทะเบียน?" |
| 6 | `/forgot-password` | ลืมรหัสผ่าน | กรอกอีเมลที่ลงทะเบียน → ส่งลิงก์รีเซ็ตรหัสผ่านทาง email |
| 7 | `/reset-password/:token` | ตั้งรหัสผ่านใหม่ | กรอกรหัสผ่านใหม่ + ยืนยัน (เข้าจากลิงก์ใน email) |
| 8 | `/directory` | ทำเนียบนักติดตาม | แสดงรายชื่อนักติดตามที่ผ่านหลักสูตร (หน้าสาธารณะ) |
| 9 | `/contact` | ติดต่อเรา | ข้อมูลติดต่อสำนักติดตามและประเมินผลฯ |

## 2. Learner Routes (ผู้เรียนทั่วไป + ผู้เรียน สตผ.)

> Prefix: `/learn`  
> ต้อง Login + role = `learner` + มี group membership ที่เหมาะสม  
> ผู้เรียน สตผ. ใช้ route เดียวกัน แต่เห็น content item ครบทุกชิ้น (ตาม `content_group_access`)

| # | Route | Page | คำอธิบาย |
|---|-------|------|----------|
| 1 | `/learn` | หน้าหลักผู้เรียน | แสดงหลักสูตรที่ลงทะเบียน, สถานะความคืบหน้า, ปุ่ม "เข้าสู่บทเรียน" |
| 2 | `/learn/courses/:courseId` | บทเรียน (Learning Path) | แสดง Learning Path: Pre-Test → Module 1-9 → Post-Test เรียงลำดับ, แสดงสถานะแต่ละ Module (ล็อค / กำลังเรียน / เรียนจบ), ระยะเวลาชม, ✓ เครื่องหมายถูกเมื่อจบ, Module ที่ล็อคจะ disable (ตาม prerequisite); content item ที่ไม่มีสิทธิ์จะซ่อนตาม content_group_access |
| 3 | `/learn/courses/:courseId/modules/:moduleId` | เนื้อหา Module | แสดงเนื้อหาราย Module: คลิปวิดีโอ (เก็บชั่วโมงรับชม, ตำแหน่งล่าสุด), ไฟล์เอกสาร/ใบความรู้ (ดาวน์โหลดได้), ลิงก์เพิ่มเติม, เรียงตาม sort_order เช่น 1.1, 1.2, 1.3 |
| 4 | `/learn/courses/:courseId/assessments/:assessmentId` | ทำแบบทดสอบ | หน้าทำแบบทดสอบ (Pre-test / Post-test / Module test): แสดงคำถามทีละข้อ/ทั้งหมด, เลือกตอบ (multiple_choice) → เฉลยทันที (auto), เขียนบรรยาย (essay) → พิมพ์ในระบบ, อัปโหลดใบงาน (file_upload) → เลือกไฟล์, แสดงครั้งที่ทำ (1/3, 2/3, 3/3), ปุ่ม "ส่งคำตอบ" |
| 5 | `/learn/courses/:courseId/assessments/:assessmentId/result` | ผลแบบทดสอบ | แสดงผลหลังส่ง: คะแนนที่ได้ / คะแนนเต็ม / ร้อยละ / ดาว, สถานะ ผ่าน/ไม่ผ่าน, ข้อที่ auto-grade → เห็นผลทันที, ข้อที่ manual → แสดง "รอผู้เชี่ยวชาญตรวจ", ข้อเสนอแนะจาก ผชช. (ถ้าตรวจแล้ว), ปุ่ม "ทำใหม่" (ถ้ายังไม่ครบ 3 ครั้ง) |
| 6 | `/learn/results` | ผลการเรียนรู้ | สรุปผลทุกหลักสูตรที่ลงทะเบียน: ตาราง Pre-test / M1-M9 / Post-test / สถานะ ผ่าน-ไม่ผ่าน, ดูผลคะแนนแต่ละ Module, ดาวน์โหลดรายงานผล PDF, วันที่ออกรายงาน |
| 7 | `/learn/certificates` | เกียรติบัตร | แสดงเกียรติบัตรที่ได้รับ (ออกอัตโนมัติเมื่อผ่านครบเงื่อนไข): แสดงภาพเกียรติบัตร, ดาวน์โหลด PDF, วันที่ออกเกียรติบัตร, ถ้ายังไม่ผ่าน → แสดงเงื่อนไขที่ยังไม่ครบ |
| 8 | `/learn/courses/:courseId/review` | รีวิวหลักสูตร | ให้ดาว 1-5 (บังคับ) + เขียนความคิดเห็น (ไม่บังคับ), ปุ่ม "บันทึก", แสดงหลังเรียนจบ เป็นเงื่อนไขรับเกียรติบัตร |
| 9 | `/learn/profile` | ข้อมูลส่วนบุคคล | แสดง/แก้ไข: คำนำหน้า, ชื่อ-นามสกุล, ตำแหน่ง, ประสบการณ์, สังกัด, สถานศึกษา, เบอร์, ปุ่ม "บันทึกการแก้ไข" (ชื่อ-นามสกุลเชื่อมโยงกับเกียรติบัตร) |
| 10 | `/learn/change-password` | เปลี่ยนรหัสผ่าน | ฟอร์ม: รหัสผ่านเดิม, รหัสผ่านใหม่, ยืนยันรหัสผ่านใหม่ |

## 3. Expert Routes (ผู้เชี่ยวชาญ)

> Prefix: `/expert`  
> ต้อง Login + role = `expert`  
> เห็นเฉพาะ 3 Modules ที่ต้องตรวจ

| # | Route | Page | คำอธิบาย |
|---|-------|------|----------|
| 1 | `/expert` | หน้าหลักผู้เชี่ยวชาญ | Dashboard สรุป: จำนวนใบงานรอตรวจ, จำนวนที่ตรวจแล้ว, แสดง Module ที่รับผิดชอบ (3 Modules) |
| 2 | `/expert/modules/:moduleId/submissions` | รายการใบงาน | ตารางรายชื่อผู้เรียนที่ส่งใบงาน Module นั้น: ลำดับ / ชื่อ-นามสกุล / วันที่ส่ง / วันที่แก้ไขล่าสุด / สถานะ (รอตรวจ / ผ่าน / รอแก้ไข), คลิกที่ชื่อเพื่อเข้าตรวจ, filter สถานะได้ |
| 3 | `/expert/submissions/:attemptId/review` | ตรวจใบงาน | แสดงคำตอบผู้เรียน (essay / ไฟล์อัปโหลด): ดาวน์โหลดใบงานที่อัปโหลด, ให้คะแนน, เขียนข้อเสนอแนะ / คำแนะนำ, เลือกสถานะ: ผ่าน / รอแก้ไข, ปุ่ม "บันทึกผลการตรวจ" → ส่งผลกลับทาง email ถึงผู้เรียน |
| 4 | `/expert/reports` | รายงานผลการเรียน | ตารางรายงานผลผู้เรียนทุกคน (เฉพาะ Module ที่รับผิดชอบ): Pre-test / M1-M9 / Post-test / สถานะ, ดูเป็นรายบุคคลได้, ดาวน์โหลด PDF รายบุคคล |
| 5 | `/expert/reports/:userId` | ผลการเรียนรายบุคคล | รายละเอียดผลการเรียนของผู้เรียน 1 คน: คะแนนแต่ละ Module, ประวัติการทำแบบทดสอบทุกครั้ง, Export PDF |
| 6 | `/expert/change-password` | เปลี่ยนรหัสผ่าน | ฟอร์มเปลี่ยนรหัสผ่าน |

## 4. Admin Routes (Admin สตผ.)

> Prefix: `/admin`  
> ต้อง Login + role = `admin`  
> จัดการทุกอย่างในระบบ + สร้างหลักสูตรใหม่ได้

| # | Route | Page | คำอธิบาย |
|---|-------|------|----------|
| 1 | `/admin` | Dashboard | สถิติภาพรวม: จำนวนผู้เรียน, จำนวนผู้ผ่าน, คะแนนรีวิวเฉลี่ย, กราฟจำนวนผู้เรียนรายเดือน, รายงานการเข้าใช้ระบบ |
| 2 | `/admin/courses` | จัดการหลักสูตร | รายการหลักสูตรทั้งหมด, สร้างหลักสูตรใหม่, แก้ไข/เพิ่มเติมข้อมูลหลักสูตร (คำอธิบาย, ระยะเวลา, เกณฑ์ผ่าน, วิทยากร) |
| 3 | `/admin/courses/:courseId/modules` | จัดการ Module | CRUD Module: ชื่อ, รายละเอียด, ลำดับ, `is_required`, `requires_expert_review`, จัดการ prerequisite (ต้องผ่านอะไรก่อน), จัดการ content access (กลุ่มไหนเห็น content item ไหน ผ่าน content_group_access) |
| 4 | `/admin/courses/:courseId/modules/:moduleId/contents` | จัดการเนื้อหา | อัปโหลดไฟล์/URL: คลิปวิดีโอ, ไฟล์เอกสาร (ใบความรู้/ใบงาน), ลิงก์, จัดลำดับเนื้อหา |
| 5 | `/admin/courses/:courseId/assessments` | จัดการแบบทดสอบ | สร้าง/แก้ไข: Pre-test, Post-test, Module test, ใบงาน, ตั้งค่า: `grading_mode` (auto/manual/mixed), `is_required_for_cert`, `max_attempts`, เพิ่มคำถาม + ตัวเลือก + เฉลย |
| 6 | `/admin/courses/:courseId/content-access` | กำหนดสิทธิ์ content | เลือกกลุ่มผู้เรียนที่มีสิทธิ์เห็น content item แต่ละชิ้น (content_group_access) |
| 7 | `/admin/groups` | จัดการกลุ่มผู้เรียน | CRUD กลุ่ม: สร้าง/แก้ไข/ลบกลุ่ม, เพิ่ม/ลบสมาชิก, ดูรายชื่อสมาชิกในกลุ่ม |
| 8 | `/admin/users` | จัดการบัญชีและสิทธิ์ | ตารางผู้ใช้ทั้งหมด: ชื่อ, ตำแหน่ง, สังกัด, เบอร์, สถานะ, แก้ไข role / กลุ่ม / รีเซ็ตรหัสผ่าน, Export ข้อมูลรายชื่อ |
| 9 | `/admin/learners` | ข้อมูลผู้เรียน | ตารางข้อมูลผู้เรียนทุกคน: ชื่อ-นามสกุล / ตำแหน่ง / ประสบการณ์ / สังกัด / สถานศึกษา / เบอร์, filter ตามหลักสูตร/กลุ่ม, Export ข้อมูลตามตารางที่แสดง |
| 10 | `/admin/reports` | รายงานผลการเรียน | ตารางผลการเรียนผู้เรียนทุกคน: Pre-test / M1-M9 / Post-test / ผ่านเกณฑ์ / สถานะ, ดูรายบุคคลได้ + ดาวน์โหลด PDF, Export ข้อมูลรายชื่อและผลรวม |
| 11 | `/admin/reviews` | รีวิวจากผู้เรียน | ตารางรีวิว: ชื่อ-นามสกุล / ความพึงพอใจ (ดาว) / ความคิดเห็น, คะแนนเฉลี่ยรวม, Export ข้อมูล |
| 12 | `/admin/certificates` | จัดการเกียรติบัตร | จัดการเทมเพลตเกียรติบัตร: อัปโหลดภาพเทมเพลต, กำหนดตำแหน่งชื่อ/วันที่, ดูรายชื่อผู้ที่ได้รับเกียรติบัตร |

## Shared Components (ใช้ร่วมกันทุก Role)

| Component | คำอธิบาย |
|-----------|----------|
| `<Navbar>` | แถบเมนูด้านบน: โลโก้ ME-Learning / หน้าหลัก / ทำเนียบนักติดตาม / ติดต่อเรา / ปุ่ม Login หรือชื่อผู้ใช้ |
| `<Sidebar>` | แถบเมนูด้านข้าง (หลัง login): เปลี่ยนตาม role — Learner: ผลการเรียนรู้, เกียรติบัตร, ข้อมูลส่วนบุคคล, เปลี่ยนรหัสผ่าน, ออกจากระบบ — Expert: ตรวจแบบทดสอบ, รายงานผล, ออกจากระบบ — Admin: เมนูจัดการทั้งหมด |
| `<ProtectedRoute>` | Guard route ตาม role: ถ้าไม่ login → redirect `/login` / ถ้า role ไม่ตรง → redirect หน้าหลักของ role นั้น |
| `<CourseCard>` | การ์ดแสดงหลักสูตร: ชื่อ, ระยะเวลา, rating, จำนวนผู้เรียน |
| `<LearningPath>` | แสดง Module เรียงลำดับ: ไอคอนสถานะ (ล็อค/กำลังเรียน/จบ), ชื่อ Module, เวลาเรียน |
| `<VideoPlayer>` | เล่นวิดีโอ + เก็บชั่วโมง: บันทึก watch_duration_sec, last_position_sec, is_completed |
| `<TestForm>` | ฟอร์มทำแบบทดสอบ: เลือกตอบ / เขียนบรรยาย / อัปโหลดไฟล์ |
| `<ReviewForm>` | ฟอร์มตรวจใบงาน (Expert): ให้คะแนน, เขียนข้อเสนอแนะ, เลือกสถานะ |
| `<CertificateViewer>` | แสดงเกียรติบัตร: ภาพตัวอย่าง + ปุ่มดาวน์โหลด PDF |
| `<DataTable>` | ตารางข้อมูล: sort, filter, pagination, ปุ่ม Export |

## Route Guard Logic

```
ผู้ใช้เข้า URL
  │
  ├─ /login, /register, /forgot-password, /, /courses/* → อนุญาตทุกคน
  │
  ├─ /learn/* → ต้อง login + role='learner'
  │    └─ เช็ค module_prerequisites → ผ่าน prerequisite แล้ว?
  │         └─ เช็ค content_group_access → ผู้เรียนอยู่ในกลุ่มที่เห็น content item นี้?
  │              └─ อนุญาต / ซ่อน content item ที่ไม่มีสิทธิ์
  │
  ├─ /expert/* → ต้อง login + role='expert'
  │    └─ เห็นเฉพาะ Module ที่ requires_expert_review=TRUE
  │
  └─ /admin/* → ต้อง login + role='admin'
       └─ เข้าถึงทุกอย่าง
```

## Notification Triggers (เหตุการณ์ที่ส่งแจ้งเตือน)

| เหตุการณ์ | ผู้รับแจ้ง | ช่องทาง |
|-----------|-----------|---------|
| ผู้เรียนส่งใบงาน (file_upload / essay) | Expert ที่รับผิดชอบ Module นั้น | In-app + Email |
| Expert ตรวจเสร็จ → ผ่าน | ผู้เรียน | In-app + Email |
| Expert ตรวจเสร็จ → รอแก้ไข | ผู้เรียน (พร้อมข้อเสนอแนะ) | In-app + Email |
| ผู้เรียนส่งแก้ไขใบงาน | Expert | In-app + Email |
| ออกเกียรติบัตรอัตโนมัติ | ผู้เรียน | In-app + Email |
